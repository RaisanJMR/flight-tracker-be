Overview

Project at a glance

Flight Tracker exposes airport records through a simple REST API with pagination and name search.

  • 86,258 Airports in the dataset
  • Pagination Page and limit on every list
  • Name search Filter airports by name

APIs

Endpoints

All responses are JSON. List endpoints support pagination and optional name search.

Base URL: https://flight-tracker-be.onrender.com

GET /api/health

Health check — confirms the API process is running.

{
  "message": "Flight Tracker API is running",
  "status": "ok"
}
Try it →
GET /api/airports

Paginated airport list. Filter by name with search or name.

Parameter Type Default Description
page number 1 Page number (min 1)
limit number 20 Items per page (1–100)
search string — Case-insensitive partial match on airport name
name string — Alias for search

Response shape

{
  "data": [ /* airport objects */ ],
  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 86258,
    "totalPages": 4313,
    "hasNext": true,
    "hasPrev": false
  },
  "search": null
}

Examples

curl "https://flight-tracker-be.onrender.com/api/airports"
curl "https://flight-tracker-be.onrender.com/api/airports?page=2&limit=10"
curl "https://flight-tracker-be.onrender.com/api/airports?search=Heathrow"
curl "https://flight-tracker-be.onrender.com/api/airports?name=Delhi&page=1&limit=5"

GET /api/airports/:id

Single airport by numeric ID. Returns 404 if not found.

Parameter Type Description
id number Airport ID (path)
